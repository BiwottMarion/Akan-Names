# Akan Name Generator
The Akan Name Generator is a simple and interactive website that determines a user's traditional Akan name based on their date of birth and gender. Inspired by the Akan culture of Ghana, the application calculates the day of the week the user was born and displays the corresponding male or female Akan name. It provides an engaging way to explore Ghanaian naming traditions while demonstrating the use of HTML, CSS, and JavaScript for dynamic web development.

# Behavior-Driven Development
### Feature: Generate an Akan name

### Scenario 1: User enters valid details

Given the user is on the Akan Name Generator website
When they enter their birth date and select their gender
Then the website should display their correct Akan name based on the day they were born

### Scenario 2: User leaves a required field empty

Given the user is on the Akan Name Generator website
When they click the Generate Name button without entering a birth date
Then the website should display an error message asking them to provide a valid birth date

### Scenario 3: User selects a different gender

Given the user has entered a valid birth date
When they change the selected gender
Then the website should display the Akan name that matches the chosen gender and birth day
# Relevance of the project
It enables one to get to know their akan names with ease just by placing the relevant details.
